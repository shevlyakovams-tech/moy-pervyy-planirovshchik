# Сначала — ты

Личный локальный ежедневник для Windows 10/11. После первоначальной настройки приложение работает без интернета, не требует регистрации и хранит записи только на компьютере пользователя.

## Системные требования

- Windows 10 или Windows 11;
- актуальный Chrome или Microsoft Edge как браузер по умолчанию;
- Node.js LTS 22.12–24.x с npm 10 или 11;
- интернет для первого получения npm-зависимостей; после настройки — не требуется.

Node.js загружается только с официального сайта: <https://nodejs.org/>. Администраторские права для проекта не нужны.

## Первый запуск

1. Закройте ранее запущенное приложение «Сначала — ты» через значок в системном трее.
2. Запустите `setup.bat` из корня проекта.
3. Дождитесь сообщения об успешной настройке. Скрипт установит строго зафиксированные зависимости, проверит миграции на временной базе, соберёт приложение и только затем подготовит постоянную базу. Окно останется открытым до нажатия любой клавиши, чтобы сообщение можно было прочитать.
4. Запустите `start.bat`.

Если `setup.bat` завершился с ошибкой, успешная сборка не объявляется и `start.bat` не должен использовать незавершённую версию.

## Обычный запуск и завершение

- Для каждого следующего запуска используйте `start.bat`; он не устанавливает зависимости и не пересобирает приложение.
- Приложение открывает страницу `http://127.0.0.1:3210` в браузере по умолчанию.
- Закрытие вкладки браузера не завершает локальный сервер.
- Значок книги остаётся в системном трее. В его меню доступны команды «Открыть», «Приостановить уведомления»/«Возобновить уведомления» и «Выход».
- Для полного завершения выберите «Выход» в трее.
- Второй запуск не создаёт второй сервер, а открывает уже работающий экземпляр.

## Настройки, уведомления и автозапуск

- Все уведомления изначально выключены. Их дни, время и повторы пользователь включает отдельно в разделе «Настройки».
- Утреннее напоминание может повториться один раз через 15 минут. Напоминания недели и привычек не повторяются автоматически; для воды доступен интервал 60, 90 или 120 минут.
- Тихие часы подавляют попавшие в них уведомления: позже они не показываются.
- Глобальная пауза доступна и на экране настроек, и в меню трея. Она действует до ручного возобновления.
- Автозапуск включается пользователем в «Настройки → Общие», действует только для текущей учётной записи Windows и запускает приложение в фоне без открытия браузера.
- Переключатель перелистывания находится в «Настройки → Внешний вид». Системное уменьшение движения Windows или браузера имеет приоритет.

## Данные и конфиденциальность

Постоянные файлы находятся в `%LOCALAPPDATA%\UtrenniyRazvorot`:

- база: `data\app.db`;
- безопасный технический журнал: `logs\app.log`;
- конфигурация запуска: `config`.

Важное ограничение: резервная копия в MVP не создаётся. SQLite-база не зашифрована и не защищена PIN-кодом; человек с доступом к вашей учётной записи Windows потенциально может прочитать файл базы. Телеметрия, внешняя аналитика, CDN и облачная синхронизация отсутствуют.

## Обновление кода

1. Завершите приложение через меню трея.
2. Замените исходные файлы новой согласованной версией, не меняя `%LOCALAPPDATA%\UtrenniyRazvorot`.
3. Запустите `setup.bat`. Новый код сначала собирается и проверяется на временной базе, затем миграции применяются к постоянной базе.
4. После успешной настройки запустите `start.bat`.

`start.bat` не заменяет настройку новой версии. Понижение версии приложения, схемы или встроенных данных блокируется. Автоматическая резервная копия перед обновлением не создаётся.

## Типовые ошибки

- **Node.js или npm не найден.** Окно не закроется автоматически: установите поддерживаемый Node.js LTS с <https://nodejs.org/>, нажмите любую клавишу для закрытия сообщения и повторите `setup.bat`.
- **Порт 3210 занят.** Завершите приложение через трей. Если оно не запущено, освободите порт 3210 от другого локального процесса; приложение не переключается на случайный порт.
- **Исходный код отличается от сборки.** Запустите `setup.bat`, затем снова `start.bat`.
- **Ошибка сборки, миграции или health-check.** Запуск новой версии блокируется. Не удаляйте базу; устраните указанную техническую причину и повторите `setup.bat`.
- **База не прошла `integrity_check`.** Приложение не исправляет и не очищает личные данные автоматически. Путь к базе указан выше.
- **Показывается `Failed to fetch`.** Локальный процесс приложения недоступен. Завершите оставшийся экземпляр через трей, снова запустите `start.bat` и нажмите «Повторить».
- **Настройка уведомления включена, но уведомления нет.** Проверьте дни, время, тихие часы и глобальную паузу; выполненная цель также подавляет соответствующее напоминание.
- **Не видно анимации перелистывания.** Проверьте переключатель внешнего вида и системную настройку уменьшения движения.

npm run build
npm run test:e2e

Приложение не предназначено для публичного распространения на текущем этапе; EXE/MSI и цифровая подпись не входят в MVP.
